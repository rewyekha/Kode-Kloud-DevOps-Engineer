# Print Environment Variables

## Kubernetes Pod: Printing Environment Variables

### Overview

This document describes the process of creating and validating a Kubernetes Pod that prints predefined environment variables. The goal is to configure a Pod using specific parameters and verify its output through logs.

***

### Objective

Create a Pod with the following specifications:

* **Pod Name**: `print-envars-greeting`
* **Container Name**: `print-env-container`
* **Image**: `bash`
* **Restart Policy**: `Never`
* **Environment Variables**:
  * `GREETING = Welcome to`
  * `COMPANY = xFusionCorp`
  * `GROUP = Industries`
*   **Command**:

    ```bash
    ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
    ```

***

### Prerequisites

* Access to a configured Kubernetes cluster
* `kubectl` CLI installed and configured on the jump host

***

### Step 1: Create Pod Manifest

Create a YAML file named `pod.yaml`:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: print-envars-greeting
spec:
  restartPolicy: Never
  containers:
    - name: print-env-container
      image: bash
      command: ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
      env:
        - name: GREETING
          value: "Welcome to"
        - name: COMPANY
          value: "xFusionCorp"
        - name: GROUP
          value: "Industries"
```

***

### Step 2: Apply the Manifest

Run the following command to create the Pod:

```bash
thor@jump-host ~$ kubectl apply -f pod.yaml
```

#### Output

```bash
pod/print-envars-greeting created
```

***

### Step 3: Verify Pod Logs

Check the logs generated by the Pod:

```bash
thor@jump-host ~$ kubectl logs -f print-envars-greeting
```

#### Output

```bash
Welcome to xFusionCorp Industries
```

***

### Step 4: Validate Configuration

Inspect the manifest file to confirm configuration:

```bash
thor@jump-host ~$ cat pod.yaml
```

#### Output

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: print-envars-greeting
spec:
  restartPolicy: Never
  containers:
    - name: print-env-container
      image: bash
      command: ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
      env:
        - name: GREETING
          value: "Welcome to"
        - name: COMPANY
          value: "xFusionCorp"
        - name: GROUP
          value: "Industries"
```

***

### Conclusion

The Pod was successfully created and executed. The environment variables were correctly configured and printed as expected in the logs. The `restartPolicy: Never` ensured the Pod did not restart after execution, preventing a crash loop.

This confirms that the setup meets all specified requirements.
