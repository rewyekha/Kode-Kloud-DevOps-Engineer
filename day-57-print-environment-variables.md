## Kubernetes Pod: Environment Variable Greeting Message

### Overview


The pod is configured to run once and exit successfully, making it suitable for simple execution tasks and testing scenarios.

***

### Objective

Create a Kubernetes Pod with the following requirements:

* Pod name: `print-envars-greeting`
* Container name: `print-env-container`
* Image: `bash`
* Environment variables:
  * `GREETING=Welcome to`
  * `COMPANY=Nautilus`
  * `GROUP=Group`
* Command to execute:

    ```
    ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
    ```
* Restart policy: `Never`
* Verify output using `kubectl logs`

***

### Prerequisites

* Kubernetes cluster is up and running
* `kubectl` is configured and connected to the cluster
* Access to a terminal (jump host)

***

### Implementation Steps

#### Step 1: Create the Pod Definition File

Create a YAML file named `print-envars-greeting.yaml`:

```bash
thor@jump-host ~$ vi print-envars-greeting.yaml
```

***

#### Step 2: Define the Pod Configuration

Add the following content to the file:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: print-envars-greeting
spec:
  restartPolicy: Never
  containers:
  - name: print-env-container
    image: bash
    command: ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
    env:
    - name: GREETING
      value: "Welcome to"
    - name: COMPANY
      value: "Nautilus"
    - name: GROUP
      value: "Group"
```

Save and exit the editor.

***

#### Step 3: Deploy the Pod

Apply the configuration using `kubectl`:

```bash
thor@jump-host ~$ kubectl apply -f print-envars-greeting.yaml
pod/print-envars-greeting created
```

***

#### Step 4: Verify Pod Creation

Check the status of the pod:

```bash
thor@jump-host ~$ kubectl get pods
NAME                    READY   STATUS      RESTARTS   AGE
print-envars-greeting   0/1     Completed   0          10s
```

The status `Completed` indicates that the container executed successfully and exited.

***

#### Step 5: View Pod Logs

Retrieve the output generated by the container:

```bash
thor@jump-host ~$ kubectl logs -f print-envars-greeting
Welcome to Nautilus Group
```

***

#### Step 6: Review YAML Configuration

Confirm the final configuration:

```bash
thor@jump-host ~$ cat print-envars-greeting.yaml
apiVersion: v1
kind: Pod
metadata:
  name: print-envars-greeting
spec:
  restartPolicy: Never
  containers:
  - name: print-env-container
    image: bash
    command: ["/bin/sh", "-c", "echo \"$(GREETING) $(COMPANY) $(GROUP)\""]
    env:
    - name: GREETING
      value: "Welcome to"
    - name: COMPANY
      value: "Nautilus"
    - name: GROUP
      value: "Group"
```

***

### Expected Output

When the pod runs successfully, the logs should display:

```
Welcome to Nautilus Group
```

***

### Conclusion

The pod successfully demonstrates how to:

* Define environment variables in Kubernetes
* Execute a shell command inside a container
* Capture and verify output using logs
* Run a one-time task using `restartPolicy: Never`

This pattern is useful for initialization tasks, testing configurations, and simple batch executions inside Kubernetes clusters.
